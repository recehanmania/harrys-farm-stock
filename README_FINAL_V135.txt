HARRY'S FARM STOCK OPNAME - V135 SIMPLE STAFF FLOW

Fokus fix V135:
1. Menu dibuat lebih gampang untuk staff:
   - Barang Masuk
   - Produksi Hari Ini
   - Barang Keluar
   - Data Stok
   - Laporan

2. Alur kerja sederhana:
   - Dus/plastik/bumbu/kentang/barang datang => Barang Masuk
   - Produksi wedges/mashed/produk lain => Produksi Hari Ini
   - Produk akhir/dus/plastik/sample/retur/rusak keluar => Barang Keluar

3. Produksi Hari Ini dibuat lebih mudah:
   - Staff pilih produk yang dibuat.
   - Isi jumlah hasil jadi.
   - Pilih bahan/bumbu/plastik/dus yang dipakai.
   - Klik simpan.
   - Produk jadi otomatis bertambah, bahan yang dipakai otomatis berkurang.

4. Fitur Resep/BOM tetap ada, tapi dipindah ke bagian Admin supaya staff tidak bingung.
   Kalau nanti resep sudah disetting, produksi bisa otomatis potong bahan tanpa input satu-satu.

5. GSheet realtime tetap memakai Apps Script V133 yang sudah ada.

Catatan:
- Mode UI default dibuat Staff supaya tampilan tidak terlalu ramai.
- Kalau butuh fitur lengkap seperti Absen, Pakai Manual, Arsip, ubah Mode UI ke Admin dan masukkan PIN admin.
