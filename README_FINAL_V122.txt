Harrys Farm V122 - Input Stok Keluar Dihilangkan

Perubahan utama:
1. Menu Input Stok sekarang hanya untuk Barang Masuk.
2. Tombol Barang Keluar di Input Stok/Data Stok dihilangkan agar stok tidak double potong.
3. Bahan yang dipakai membuat produk, contoh bumbu A/B/C, plastik produksi, kentang, tepung, dipotong lewat menu Produksi.
4. Menu Pabrik hanya untuk produk jadi keluar ke customer/gudang, plus auto potong dus/plastik pengiriman.
5. Alur dibuat lebih aman untuk operasional harian.

Contoh alur:
- Beli bumbu A 10 kg: Input Stok > Barang Masuk.
- Produksi Wedges: Produksi > isi hasil Wedges + bahan dipakai bumbu A/B/C/plastik/kentang.
- Kirim Wedges ke customer: Pabrik > Barang Keluar dari Pabrik.
